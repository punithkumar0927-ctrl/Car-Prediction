# 🚗 Car Price Prediction Using Machine Learning

## 📌 Project Overview

Car Price Prediction is a Machine Learning regression project that predicts the price of a car based on different features such as engine size, horsepower, fuel type, car body, wheelbase, mileage, and other specifications.

The project uses the **CarPrice_Assignment.csv** dataset and compares multiple Machine Learning algorithms to identify a suitable model for predicting car prices.

---

## 🎯 Objectives

* Analyze car-related data using Python.
* Perform data cleaning and preprocessing.
* Explore relationships between car features and price.
* Convert categorical features into numerical values.
* Train different Machine Learning regression models.
* Compare model performance.
* Predict the price of a new car.

---

## 📂 Dataset

The dataset contains information about different cars and their specifications.

### Important Features

| Feature          | Description           |
| ---------------- | --------------------- |
| `car_ID`         | Unique ID of the car  |
| `symboling`      | Insurance risk rating |
| `CarName`        | Name of the car       |
| `fueltype`       | Fuel type             |
| `aspiration`     | Aspiration type       |
| `doornumber`     | Number of doors       |
| `carbody`        | Type of car body      |
| `drivewheel`     | Drive wheel type      |
| `enginelocation` | Engine location       |
| `wheelbase`      | Wheelbase of the car  |
| `carlength`      | Length of the car     |
| `carwidth`       | Width of the car      |
| `carheight`      | Height of the car     |
| `curbweight`     | Weight of the car     |
| `enginetype`     | Engine type           |
| `cylindernumber` | Number of cylinders   |
| `enginesize`     | Engine size           |
| `fuelsystem`     | Fuel system           |
| `horsepower`     | Horsepower            |
| `peakrpm`        | Peak RPM              |
| `citympg`        | City mileage          |
| `highwaympg`     | Highway mileage       |
| `price`          | **Target variable**   |
